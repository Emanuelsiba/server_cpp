To run the server, first you must download xmake.
you can search in the web how to download "xmake" for you OS.

After that, you'll run "git clone https://github.com/Emanuelsiba/server_cpp.git" in your terminal to download the code.


Server pc
And to run you can use the command "xmake && xmake r" in you terminal, inside the code folder, and you'll shows something like "Server running at http://localhost:8080" that means server is on.
you can show the ip typing "hostname -I or "ifconfig" in linux system and port is 8080.  If you are using another operating system, search how to see the ip in you OS.

another device
To download the files you access the browser in another device typing ip:port.
